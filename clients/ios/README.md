# iOS client (Swift + SwiftUI)

Phase 5, spec 052-ios-mvp. Swift 5.10, iOS 16+.

- The core arrives as an `XCFramework` (device + simulator slices built with `cargo`) plus the
  Swift bindings generated by uniffi (spec 040-uniffi), consumed as a Swift package. Generated
  code is not committed (AGENTS 16).
- No GRDB, no SQLite, no UserDefaults with secrets: storage belongs to the core (the
  boundary types are listed in `docs/spec.md` §9). Passwords cross the boundary as
  `[UInt8]` and are zeroized after the call.
- Device security measures of `docs/spec.md` §8 (Keychain with Secure Enclave where available,
  app lock, backup exclusion, notifications, clipboard).
- UI strings in `Localizable.xcstrings`: English source, plus Spanish, French, Catalan and
  Italian (`docs/spec.md` §12).

Standard: `.claude/skills/swift/SKILL.md`.
