# Android client (Kotlin + Jetpack Compose)

Phase 5, spec 051-android-mvp. minSdk 26.

- The core arrives as a native library (`libprivatechat_core.so` per ABI, built with
  `cargo-ndk`) plus the Kotlin bindings generated by uniffi (spec 040-uniffi). Generated
  code is not committed (AGENTS 16).
- No Room, no SQLite, no SharedPreferences with secrets: storage belongs to the core (the
  boundary types are listed in `docs/spec.md` §9). Passwords cross the boundary as
  `ByteArray` and are zeroized after the call.
- Device security measures of `docs/spec.md` §8 (Keystore, app lock, backup exclusion,
  screenshot blocking, notifications, clipboard).
- UI strings in `res/values/strings.xml`: English source, plus Spanish, French, Catalan and
  Italian (`docs/spec.md` §12).

Standard: `.claude/skills/kotlin/SKILL.md`.
