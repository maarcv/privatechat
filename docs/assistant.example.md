# assistant.md — personal preferences for working with an AI assistant

Copy this file from `docs/` to `assistant.md` at the repository root and edit it. `assistant.md` is
git-ignored: it is yours, not the project's. `CLAUDE.md` tells the assistant to read it.

It can set the language of the conversation, tone, how much to explain, when to ask before
acting, and similar preferences. It cannot relax `AGENTS.md`: everything that goes into the
repository (code, comments, docs, specs, ADRs, commit messages, PRs, issues) is in English.

## Preferences

- Talk to me in English.
